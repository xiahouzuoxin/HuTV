HuTV 支持 CMS JSON 点播接口和 M3U / TXT 直播列表，提供分类浏览、按源搜索、分线路选集和视频播放。搜索历史与观看进度保存在本机，支持继续观看、自动播放下一集、触屏快进和亮度音量调节。可选择系统播放器或 VLC 播放内核。

媒体可用性、格式支持和访问权限取决于相应服务。请仅添加并播放你有权访问的内容。

## 审核备注草稿

这是原生媒体订阅与播放客户端，不要求创建 App 账号。支持 CMS JSON、M3U / TXT 及 TVBox JSON 配置中的兼容接口，不下载或执行 Spider JAR / JS 爬虫代码。

当前版本包含十三个默认点播接口和三个直播列表。提交前必须核实并提供其内容与服务授权；本草稿不作为授权声明。

审核演示步骤待补：演示订阅 URL、权利来源、分类/影片/集数路径、可用地区与预期播放表现。勿填写未获授权的影视内容，也不要为审核隐藏真实功能。

隐私入口：设置 → 隐私与数据。搜索及观看历史保存在本机，可在该页清空。搜索与播放请求会直接访问相关媒体服务。

当前 HTTP 兼容例外用于用户导入的 HTTP 订阅/API/媒体。提交前核实是否确有必要并按最终配置更新说明。
