# HuTV 图标

使用内置 image_gen 生成。最终采用用户指定的浅色蓝绿标识与透明背景。

- `HuTV-mark-transparent.png`：透明原图。
- `../App/Assets.xcassets/AppIcon.appiconset/`：安装图标；为满足应用图标要求，使用极浅底色并导出 iPhone / iPad 所需尺寸。

## 透明原图最终提示词

Use case: logo-brand. Create one clean, elegant icon mark for an iOS video subscription player, TVBox. GENUINELY TRANSPARENT BACKGROUND, no square tile, no backdrop, no outer rounded rectangle. One cohesive softly folded play-button ribbon/screen symbol, light pastel sky blue and fresh mint, delicate pearlescent glass depth, mostly simple flat readable geometry, restrained soft shading. Airy minimal style, crisp silhouette, generous transparent margin, centered square composition 1024x1024. No words, no letters, no brand marks, no watermark, no checkerboard drawn into image, no heavy shadows, no dark colors. Must be attractive at small app-icon sizes.

## 安装版编辑提示词

Prepare this exact transparent pastel blue/mint play-ribbon mark as an iOS installation app icon. Preserve the mark's design, pastel colors, proportions and centered composition. Only replace transparency with a uniform very pale ivory-white background (#F7FAFC). Full bleed opaque square, no rounded outer corners, no text, no extra objects, no shadows beyond existing soft shading. Clean any tiny detached speckles around the mark. Keep the cohesive emblem large with comfortable margins.
